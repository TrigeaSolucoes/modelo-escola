# Ponte Idiomas e Reforço — site-modelo

Site-modelo **fictício** de Escola de cursos livres (inglês e reforço) em Governador Valadares (MG), criado pela [Trígea Soluções](https://trigea.com.br/) para mostrar como pode ficar o site de um negócio desse ramo.
Negócio, pessoas, telefones e endereços são inventados.

Demonstração: https://trigeasolucoes.github.io/modelo-escola/

Quer um site assim para o seu negócio? Fale com a Trígea: https://trigea.com.br/
